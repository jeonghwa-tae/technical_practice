# technical_practice
テクニカルスキルチェック用リポジトリ


[ ] 1. 全体像の確認 (git status)

変更・作成・削除されたファイルの全体数を把握し、意図しないファイルが含まれていないか確認する。

[ ] 2. 意図したファイルのみステージ (git add <ファイル名>)

git add . で丸ごと追加せず、今回コミットすべきファイルだけを個別（または git add -p）でステージングする。

[ ] 3. ステージ済み内容の全文通読 (git diff --staged)

ステージングした変更を1行ずつ通読し、デバッグログや不要なコメント、秘密情報が含まれていないかチェックする。

[ ] 4. 未ステージ残りの確認 (git diff)

ステージングから外した残りの変更が、次以降の作業に回す意図通りのものか確認する。

[ ] 5. 未追跡ファイルの取りこぼし確認 (git status --porcelain)

新規作成した設定ファイルやソースコードなど、追跡漏れ（??）がないか確認する。
